01 · Prepare

Download the template

Use the Students sheet: enter the school’s state and city once at the top, then add one student per row below. State, gender and participant group have dropdowns. The Instructions sheet is only a guide.

Download Excel template ↓

Open the downloaded .xlsx file in a spreadsheet app and enable editing if prompted. Select an entry cell to use its dropdown. If your mobile app does not show the choices, enter an option exactly as listed in Instructions or open the file in desktop Excel.

  • An email can be shared by students of the same school or college.
  • Each student needs a different phone number. Use 10-digit Indian mobile numbers; +91 will be added during registration.
  • This collection is for Bhagavad Gita Quiz only.
  • You can send additional or corrected files using the same school name. Earlier files are retained.
